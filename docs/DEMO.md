# 모두의창업 발표를 위한 3분 시연

이 문서는 시제품의 사용 순서입니다. 지원사업의 신청 자격·공고·평가기준을 확인한 문서는 아닙니다. 화면의 사용자 수·매출 관련 지표·가맹점 수는 **시연 예시**로 소개하고 실제 실적으로 제시하지 않습니다.

## 시작 전

`npm run dev`로 앱을 실행합니다. 우측 상단 프로필 → **시연 데이터 초기화**를 누르면 기본 잔액 2,480 HC, 1,860 XP, 5,432보로 시작합니다. 발표 중에는 예시 수치만 입력하세요. 가상 활동은 브라우저에 남으므로 새 시연 전 초기화하면 같은 순서를 반복할 수 있습니다.

## 0:00–0:30 · 문제와 해결

홈에서 설명합니다.

> “건강을 위해 움직여야 한다는 사실은 알지만, 매일 실천하기는 어렵습니다. 헬시캐시는 현직 치과의사의 기획을 바탕으로 걷기·건강 지식·동네 혜택을 연결합니다. 소액 보상은 시작을 돕고, XP 등급과 꾸준한 실천은 지속을 돕습니다.”

동네 선택 버튼에서 닉네임·효자동을 설정할 수 있습니다. 가입 보상은 기본 예시 잔액에 포함되므로 반복 설정으로 캐시가 늘어나지 않습니다.

## 0:30–1:00 · 건강 실천과 보상

**미션·챌린지 → 시연 걸음 1,000보 추가**를 두 번 누릅니다. 목표가 7,000보를 넘으면 걷기 미션에서 보상을 받습니다. 잔액은 2,510 HC가 되고 XP도 60 증가합니다. 보상 버튼은 완료 상태로 잠깁니다.

> “실제 서비스에서는 건강앱과 연결합니다. 지금은 예시 걸음으로 흐름을 보여드립니다. 같은 날의 같은 미션은 한 번만 보상합니다.”

**1분 건강글 → 오늘의 건강글 읽기**를 열고 출처·감수 전 표시를 보여줍니다. 본문을 확인한 뒤 퀴즈 정답 ‘그렇다’를 선택합니다. 화면 체류 10초 뒤 +100 HC를 받을 수 있습니다.

> “건강 정보는 출처와 감수 상태를 드러내고, 광고 영역은 분리합니다. 현재 글은 최종 감수 전 샘플입니다.”

## 1:00–1:40 · 동네에서 사용

**동네 혜택 → 온기 가득 국밥 → HC 사용 체험하기**로 이동합니다. 시연 전용 QR을 보여주고 결제 금액 10,000원·사용 HC 1,000으로 확정합니다. 실제 결제는 발생하지 않습니다.

> “보상은 동네 소비로 이어집니다. 가맹점은 10% 할인분을 판촉비로 부담하고, 운영사는 현금 정산을 하지 않는 구조를 기획했습니다. 병의원과 약국은 사용처에서 제외합니다.”

결제 완료 후 **내역 확인하기**에서 적립·차감이 한 원장에 남는 것을 보여줍니다. 실제 서비스의 원장은 서버에서 검증해야 합니다.

## 1:40–2:10 · 선택 기반 건강 기록

**건강 기록**에서 별도 선택 동의와 보관 범위를 보여줍니다. 체크 후 **동의하고 기록 시작하기**를 누르고 혈압 `120 / 78`을 입력합니다. 건강 기록과 하루 1회 보상 흐름을 보여줍니다.

> “건강 정보는 별도 선택입니다. 동의하지 않아도 걷기와 혜택은 쓸 수 있습니다. 이 시제품에서는 수치를 서버나 브라우저 저장소에 남기지 않습니다.”

**동의 철회·기록 삭제**를 눌러 기록이 사라지는 것을 확인합니다.

## 2:10–2:50 · 수익 구조와 확장

PC 사이드바 또는 모바일 메뉴에서 **운영 대시보드**로 이동합니다.

> “재원은 스폰서 선입금, 가맹점 월정액, 병원 월정액 노출 광고로 나눕니다. 상담·환자 수에 비례해 과금하거나 의료 이용에 포인트를 주지 않습니다. 발행량만큼이나 사용과 소각을 관리합니다.”

HC 경제 지표는 실제 성과가 아닌 예시임을 밝힙니다. **콘텐츠 감수**에서는 검수 흐름을, **병원 파트너**에서는 심의 미확인 비공개 상태를 보여줍니다. 심의번호 등록 시연을 해도 증빙 확인 대기 상태에 머뭅니다.

## 2:50–3:00 · 다음 검증

> “지원금으로 실제 건강 연동·서버 원장·개인정보 보호 기반을 구현하고, 전주 가맹점 파일럿에서 반복 사용과 지역 소비 전환을 검증하겠습니다.”

구체적인 파일럿 규모·예산·사업 일정은 실제 확보된 제휴와 공고 기준으로 확정합니다. 문서의 예상 수치나 공급업체 실적을 창업팀의 실적으로 사용하지 않습니다.
